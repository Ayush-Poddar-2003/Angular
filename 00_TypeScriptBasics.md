# TypeScript Fundamentals

TypeScript is a **superset of JavaScript** that adds **types, compile-time checking, and better tooling**.  
Angular is written **entirely in TypeScript**

---

## Why TypeScript for Angular?
- Catches errors at compile time
- Improves code readability & maintainability
- Enables Angular features like:
  - Dependency Injection
  - Decorators (`@Component`, `@Injectable`)
  - Strict typing in services, forms, APIs

---
